# Smartcart-Customer-Segmentation-System

# 🛒 SmartCart Customer Segmentation

An end-to-end **Customer Segmentation** project using **Unsupervised Machine Learning** to group customers based on their demographic information, purchasing behavior, and customer activity.

The project uses **Agglomerative Hierarchical Clustering** and provides an interactive **Streamlit web application** that predicts the customer segment for a new customer.

## 📌 About The Project

Customer segmentation is the process of dividing customers into groups based on similarities in their characteristics and behavior.

**SmartCart Customer Segmentation** analyzes customer information such as income, age, purchasing behavior, web activity, spending, education, living arrangement, and customer tenure to identify different customer segments.

The project follows a complete machine learning workflow:

```text
Data
 ↓
Data Cleaning
 ↓
Feature Engineering
 ↓
One-Hot Encoding
 ↓
Feature Scaling
 ↓
PCA
 ↓
Clustering
 ↓
Cluster Analysis
 ↓
Cluster Centers
 ↓
New Customer Input
 ↓
Nearest Cluster
 ↓
Customer Segment
