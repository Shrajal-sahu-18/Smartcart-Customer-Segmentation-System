# Smartcart-Customer-Segmentation-System

# 🛒 SmartCart Customer Segmentation

An end-to-end **Customer Segmentation** project using **Unsupervised Machine Learning** to group customers based on their demographic information, purchasing behavior, and customer activity.

The project uses **Agglomerative Hierarchical Clustering** and provides an interactive **Streamlit web application** that predicts the customer segment for a new customer.

## 📌 About The Project

Customer segmentation is the process of dividing customers into groups based on similarities in their characteristics and behavior.

**SmartCart Customer Segmentation** analyzes customer information such as income, age, purchasing behavior, web activity, spending, education, living arrangement, and customer tenure to identify different customer segments.

🤖 Clustering

The final clustering algorithm used in this project is:

Agglomerative Hierarchical Clustering

AgglomerativeClustering(
    n_clusters=4,
    linkage="ward"
)

The model divides customers into 4 clusters based on similarities in their transformed feature representations.

👥 Customer Segments

After analyzing the cluster characteristics, descriptive names were assigned to the clusters.

Cluster	Customer Segment
0	Low-Spending Family Customers
1	High-Value Partner Customers
2	Low-Activity Solo Customers
3	High-Value Solo Customers

Note: These names are interpretations of the observed cluster characteristics. They are not labels directly generated by the clustering algorithm.

Cluster 0 — Low-Spending Family Customers

Customers with relatively lower income and spending, with a larger proportion living with a partner.

Cluster 1 — High-Value Partner Customers

Higher-income and higher-spending customers, mostly living with a partner and showing purchasing activity across multiple channels.

Cluster 2 — Low-Activity Solo Customers

Lower-income and lower-spending customers, mostly living alone with relatively low purchase activity.

Cluster 3 — High-Value Solo Customers

Higher-income and higher-spending customers, mostly living alone with relatively strong purchase activity.

🔮 New Customer Prediction

Agglomerative Clustering does not provide the standard .predict() method for assigning unseen customers.

Therefore, this project uses a nearest cluster center approach.

For a new customer, the same preprocessing pipeline is applied:

New Customer
     ↓
One-Hot Encoding
     ↓
Feature Scaling
     ↓
PCA Transformation
     ↓
New PCA Point
     ↓
Calculate Euclidean Distance
     ↓
Compare With Cluster Centers
     ↓
Nearest Cluster
     ↓
Predicted Customer Segment

The Euclidean distance is calculated using:

np.linalg.norm(new_pca[0] - center)

The cluster with the smallest distance is selected as the predicted cluster.
